# E-Commerce Order, Return and Refund Management System

## Project Description

A database-driven e-commerce management system developed as a DBMS course project.

The system manages customers, products, orders, returns, and refunds through a web-based interface connected to a MySQL database.

## Technologies Used

- Next.js
- Node.js
- Express.js
- MySQL
- REST API

## Main Modules

- Customer Management
- Product Management
- Order Management
- Return Management
- Refund Management
- Admin Management

## System Architecture

Frontend (Next.js)
        ↓
Backend (Node.js + Express)
        ↓
MySQL Database

## Database

The main entities of the system are:

- Customers
- Products
- Orders
- Returns
- Refunds

## Project Features

- Add, view, edit and delete products
- Manage customers
- Manage orders
- Request and manage returns
- Process refunds
- View order, return and refund information
- Admin management interface
